**Дисципліна:** Об'єктно-орієнтоване програмування

### Порядок виконання роботи

У всіх завданнях, крім зазначених у завданні операцій, обов'язково повинні бути реалізовані наступні методи:

* метод ініціалізації Init();
* метод введення із клавіатури Read();
* метод вивідення на екран Display();
* перетворення в рядок toString().

### Варіант 10

Створити клас Time для роботи згодом у форматі «година:хвилина:секунда».  
Клас повинен містити в собі не менш чотирьох функцій ініціалізації: числами, рядком (наприклад, «23:59:59»), секундами й часом.  
Обов'язковими операціями є: обчислення різниці між двома моментами часу в секундах, додавання часу й заданого кількості секунд,  
вирахування із часу заданого кількості секунд, порівняння моментів часу, переведення у секунди, переведення у хвилини (з округленням до цілої хвилини).
